1. Чем x += 5; отличается от x = x + 5;?
Разница только в записи. += такая форма делает код короче и понятнее

2. В чём разница между x++ и ++x, если результат сразу используется в выражении?
x++ сначала отдаёт старое значение, а потом увеличивает. ++x все то же, но наоборот

3. Какой тип данных всегда получается в результате оператора сравнения?
Всегда bool 

4. Что такое «короткое замыкание» в && и ||?
Короткое замыкание — это когда программа не проверяет второе условие. если по первому условию уже понятнол, что будет в итоге, второе условие оно даже не считает

5. Расставьте приоритет для выражения 10 - 2 * 3 + 4 / 2
Сначала умножение и деление: 2 * 3 = 6
 4 / 2 = 2
Потом вычитание и сложение: 10 - 6 + 2 = 6

6. Почему хорошим тоном считается расставлять скобки даже там, где они не 
обязательны по приоритету операций?
Они делают код понятнее для человека
